# CSV Output for No Tags in Exicon Data

**Author:** Andy Pickler
**Date:** 2025-12-16

---

## What & Why

**What are we building?**

- We need to create a CSV file that shows the Exicon data that has no tags

**Why does it matter?**

- This indicates data that has missing info (tags) that could be added and thus enhance the data
- All users of the Exicon (to include humans and AI) would benefit from being able to properly identify Exicon data

---

## How

**Approach:**

- Add a capability to the @packages/exicon-to-csv package to output a CSV for Exicon data that is missing tags

**Key Details:**

- CLI commands: `pnpm --filter exicon-to-csv run no-tags`
- Existing code should be reused where possible; eliminate unnecessary duplication
- CSV output location should be the same as with other CSV files (`output/` directory at repo root)
- CSV output filename: `exicon-no-tags_YYYY-MM-DD.csv` (with datestamp like other CSV files)
- CSV output file should only have the columns "name" and "description"
- Include exercises where `tags` is undefined/missing OR where `tags` is an empty array `[]`
- Sort CSV rows alphabetically ascending (A-Z) by the "name" column
- Console output: Print a summary showing count of exercises without tags vs total exercises
  - Example: "Found 15 exercises without tags out of 250 total exercises. Wrote to output/exicon-no-tags_2025-12-16.csv"

---

## Acceptance Criteria

How we know it's done:

- [ ] Running `pnpm --filter exicon-to-csv run no-tags` produces a CSV file of all Exicon data that has no tags
- [ ] CSV file is created at `output/exicon-no-tags_YYYY-MM-DD.csv` with current date
- [ ] CSV file contains only "name" and "description" columns
- [ ] CSV includes exercises where tags are undefined/missing OR empty array
- [ ] CSV rows are sorted alphabetically by name (A-Z)
- [ ] Console output shows summary: count of exercises without tags vs total exercises count
- [ ] Console output shows the file path where CSV was written
